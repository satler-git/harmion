# Assets

`docs/` から移した画像と設計ソース。文書からの相対リンクで参照する。

| ディレクトリ | 内容 |
|---|---|
| `mote/` | Mote HUD と Mote v2 のスクリーンショット |
| `wiki/` | Wiki GUI・モックアップのスクリーンショット |
| `admin/` | harmion-admin と Worker 管理画面のスクリーンショット |
| `source/` | 編集可能な設計ソース（`.fig`, 旧モックアップの `.html`） |

`obtainium-badge.png` は Obtainium の "Get it on Obtainium" バッジ。出典: <https://github.com/ImranR98/Obtainium/blob/main/assets/graphics/badge_obtainium.png>（GPL-3.0）。ルート README から Obtainium の追加リンクに使う。

`.fig` は OpenPencil で開く。`.html` は v5 のモックアップで、[Wiki GUI refresh](../apps/wiki/design.md) に置き換えられている。
