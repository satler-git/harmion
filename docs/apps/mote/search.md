# Mote Android版のライブ検索（初期要件）

## 目的

Captureが一時的に増えたときや、過去のCaptureを見返したいときに、覚えている語句から目的のCaptureをすぐに見つけられるようにする。

## 検索操作

- ホーム画面から検索欄を開ける。
- 検索欄への入力に合わせて、その場でCapture一覧を絞り込む。検索の確定操作は不要とする。
- 検索開始時は、現在表示しているInbox／AllとPinnedの状態を引き継ぐ。
- 検索中もInbox／AllとPinnedを切り替えられる。切り替えても検索語は保持する。アーカイブ済みのCaptureはAllで検索できる。
- 検索語を消すと、現在のフィルターに対応する通常の一覧に戻る。検索を閉じると、検索開始前の一覧に戻る。

## 一致判定と結果表示

- Captureの本文を部分一致で検索する。「同期」のような短い日本語でも検索できる。
- 結果は既存の時系列順で表示する。長文では、一致した箇所の前後を一覧から確認できるようにする。
- 結果からCaptureの詳細を開ける。詳細から戻ったときは、検索語とフィルターを保持する。
- 一致するCaptureがない場合は、その旨を表示する。読み込み中や再接続中は、その状態を表示する。

## データと更新

- 既存のCapture購読で取得した本文を端末上で絞り込む。検索語の入力ごとにHarmionへ問い合わせる必要はない。
- 検索中に購読から追加・更新・削除が届いた場合は、現在の検索語とフィルターに基づいて結果を更新する。
- Harmionの標準Search API、関連度順、意味検索、アプリ横断検索は初期実装の対象外とする。

## 利用後に見直す点

- Inbox内で特定のCaptureを探す場面と、Allに広げてアーカイブ済みのCaptureを探す場面が、それぞれどの程度あるか。
- Captureが増えたときも、入力に対して結果がすぐに更新されるか。
